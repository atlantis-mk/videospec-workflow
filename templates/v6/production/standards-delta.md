# Standards delta

A production only changes durable series or brand standards when necessary. Add one file per domain, for example `visual.md`, using any of these sections:

```markdown
## ADDED Standards

### Standard: New rule name

The production SHALL ...

#### Check: Acceptance

- **WHEN** ...
- **THEN** ...

## MODIFIED Standards

### Standard: Existing rule name

...complete replacement block...

## REMOVED Standards

### Standard: Existing rule name

Reason: ...
```
